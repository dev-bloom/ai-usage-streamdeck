Typed into the frontmost terminal on press. Defaults to plain codex — leave the box empty to keep that default. Append your own flags here if you want them; none are assumed for you.

That default only works if a codex CLI is on your shell's PATH. If it isn't — a standalone @openai/codex npm install can fail this way, and currently does on the machine this plugin was built on — a working binary already exists inside the ChatGPT desktop app. Put its full path in this box instead:

/Applications/ChatGPT.app/Contents/Resources/codex

optionally followed by --dangerously-bypass-approvals-and-sandbox to skip confirmation prompts and sandboxing — verified from that binary's own --help, not guessed, and exactly as dangerous as it sounds. That path reaches inside an app bundle, so a major ChatGPT.app update can move or rename it; the plain codex default is what to use once a standalone CLI is actually on PATH.

On, the command runs immediately. Off, it is only typed — you press Enter yourself, which is a safer way to try a new command for the first time.

Off by default. This key always refuses to type into an app it cannot identify as a terminal. macOS cannot tell whether VS Code's or Cursor's integrated terminal panel or an ordinary source file has focus — only that the editor itself is frontmost — so turning this on means a press can type a shell command into whatever file you were last editing.

The first press asks macOS for permission (Automation for Terminal/iTerm, Accessibility for everything else). Accept the prompt; it is only asked once per app.
